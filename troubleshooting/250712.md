## 모듈 도커화 이후 응답 출력 형태 오류
json형태로 응답이 출력됨
(답변 자체는 옳게 나옴)

```python
try:
            r = requests.post(
                url="https://api.openai.com/v1/chat/completions",
                json=payload,
                headers=headers,
                stream=True,
            )

            r.raise_for_status()

            if body["stream"]:
                return r.iter_lines()
            else:
                res = r.json()
                steps = res.get("message", {}).get("steps", [])
                if steps and isinstance(steps[0], dict):
                    return steps[0].get("tool_response", "[No response found]")
                else:
                    return "[Invalid LLM response format]"
```

해결을 위해 tool_response부분의 메시지를 뽑아보았으나 해결하지 못함
